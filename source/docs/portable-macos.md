# MarketGO Portable — Mac 독립 실행판

압축을 풀고 이 안내 파일과 같은 폴더의 `Start-MarketGO.command`를 더블클릭한다.
통합 ZIP에서는 `MarketGO/Mac-AppleSilicon/` 폴더에 있다.
포함된 실행 파일이 이 PC에서 거래소 시세를 수집하고 계산하며 로컬 화면을 연다.
공지 수집과 공지 AI 작업은 비활성화한다.
Go·Node·PowerShell·PostgreSQL 설치가 필요하지 않다. Windows EXE 대신 macOS 네이티브 실행 파일을 포함한다. 거래소 연결에는 인터넷이 필요하다.
종료는 실행 터미널에서 Ctrl+C를 누른다.

## 두 가지 코인 보기

- **코인 보기 (오늘)**: 5개 거래소의 공식 KRW 마켓 최근 24시간 티커 거래대금을 10초마다 조회한다.
  코빗·고팍스를 포함하며, 종가×거래량 추정이나 시간봉 혼합을 하지 않는다. 미수신·오래된 티커는 미확인으로 남는다.
- **코인 보기 (과거)**: 이 PC가 확보한 공식 KRW 시간봉으로 날짜별 표를 표시한다. 조회일은 오늘 포함 최근 8일이다.
  BTC·USDT 시간별 환산 자료와 캐시 범위 밖의 과거 자료는 미확인으로 남는다.
- **실시간 보기**: 오른쪽에서 선택한 구간의 실제 체결 금액을 매초 조회한다. 코인별 금액과 거래소 구성비는
  같은 서버 응답을 사용한다. 날짜 입력은 비활성화하고 선택 구간·수신 시각과 갱신 지연을 표시한다.
  작은 금액을 읽을 수 있도록 원·만·억 단위를 사용한다. 기록 조회나 누락 복구를 실행하지 않는다.

검색·거래소·마켓·상장 구조·점유율 필터와 정렬을 지원한다. 오른쪽 거래소를 클릭하면 왼쪽도 그 거래소로
필터링하며, 다시 클릭하면 전체로 돌아간다. 현재 탭을 유지하고 목록의 맨 위부터 보여 준다.
상단 새로고침은 현재 탭의 데이터를 재조회하며 검색·필터와 실시간 스트림을 유지한다.

## 화면 조작

- 상단은 거래금액·거래소별 점유율과 실시간 요약이다. 기본 금액 소수점은 1자리다.
- 화면은 100% 배율이며 조회일 입력을 크게 표시한다. 빗썸 요약은 10초·30초·1분·10분·30분·1시간이다.
  10분 이상은 10초마다 갱신하며 기준 시각과 부분 관측 여부를 툴팁으로 확인한다.
- 실시간 표의 순위 이동은 240ms로 연결한다. 시스템의 동작 줄이기 설정에서는 효과를 생략한다.
- 좌우는 5:5이며 각각 스크롤한다. 왼쪽 검색·필터·표 헤더는 고정한다.
- 오른쪽은 거래소 구성, 실시간 그래프, 직전 구간 비교 순서다.
- 구간 선택 버튼을 펼쳐 10초~24시간을 고른다. 그래프의 30초·1분·2분·전체는 별도의 표시 범위다.
- 그래프의 24시간은 공식 티커이며 약 10초 주기에 맞춰 표시한다. 그 밖의 구간은 실시간 관측값이다.
- 필터 메뉴는 선택 항목에서 열리고 방향키·Home·End·Enter·Escape를 지원한다. 검색창 Escape는 검색어를 지운다.

## 저장과 빌드

SQLite 메모리 모드를 사용하므로 종료하면 수집 이력이 사라진다. 초기에는 긴 구간의 관측 자료가 부족할 수 있다.
LLM은 비활성화되어 있다. `127.0.0.1:20560`은 이 PC의 주소이며 운영 서버의 화면/API를 사용하지 않는다.
Apple Silicon(M 시리즈) Mac용이다. Intel Mac용은 통합 ZIP에 포함하지 않는다.
Apple Silicon에서 실행과 실제 거래소 데이터 수신을 검증한다.
배포용 Apple 개발자 서명·공증은 하지 않았다. macOS 보안 경고가 표시될 수 있다.

소스 루트에서 `sh scripts/build-portable-macos.sh arm64`로 재생성한다. 출력은 `dist/macos-native-portable/`이다.
`VITE_PORTABLE_DESKTOP=true` 빌드가 포터블 전용 화면을 선택한다.
